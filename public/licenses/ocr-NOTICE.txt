The distributed Tesseract worker retains its upstream attribution notices
in ocr/worker.min.js.LICENSE.txt. Licenses for bundled JavaScript dependencies
are included in the ocr-*.txt files in this directory.

KeyPilot's detection, image preprocessing, candidate ranking and confirmation
interface are separate application code. All OCR files and language data are
loaded from the installed extension; no CDN or hosted recognition API is used.
