# 完整备份与迁移（1.7）

管理页顶部点击“完整备份”，或在设置中打开“账户&数据”，选择“导出完整加密备份”。也可通过弹窗的“更多操作 → 设置”进入设置页。

## 文件包含什么

| 内容 | 完整加密备份 |
| --- | --- |
| 登录账号、密码和账号附加字段 | 包含 |
| 最近 10 次旧密码、网站恢复码及使用状态 | 包含；不同于 KeyPilot 主密码恢复码 |
| 2FA 密钥、名称、算法、位数、周期、账号关联及已移除记录 | 包含，恢复后无需重新扫码 |
| 提醒事项、账号关联、完成和确认状态、开关及声音设置 | 包含；恢复后重新安排提醒，详见 [浏览器提醒](reminders.md) |
| 保密笔记、个人信息、填表资料及站点绑定 | 包含 |
| 文件夹和回收站 | 包含 |
| 插件偏好、安全设置、黑名单、静默规则 | 包含 |
| 站点识别规则、字段映射模板、导入进度 | 包含 |
| 已设置的恢复码对应的恢复能力 | 保留；不会显示恢复码原文 |
| 浏览器权限、浏览器分配的快捷键、临时会话、诊断日志、尚未确认保存的网页候选 | 不包含 |

文件由导出时的主密码保护。账号 CSV/账号 JSON 只导出账号，不带密码历史、网站恢复码或 2FA；`.kpfill` 只导出填表资料，规则文件只导出站点规则。这些分类文件不能用于完整恢复。Google 迁移二维码、单个 TOTP 导出二维码也不是 KeyPilot 的完整备份。

## 新安装恢复

1. 在弹窗、管理页或设置页选择“已有备份？直接恢复”。
2. 选择完整加密备份 JSON，并输入这份备份对应的主密码。
3. 预览各类记录数量，确认后点击“恢复到本机”。预览和取消不会创建或写入密码库。
4. 恢复后使用备份对应的主密码；已配置的原恢复码仍有效。浏览器权限和快捷键需在新设备检查。

如果预览期间本机已经创建了密码库，会阻止首次恢复覆盖现有数据，需先解锁后再选择合并或替换。

## 已有密码库恢复

先解锁当前密码库，上传文件并预览。

**合并（默认）**保留当前主密码。预览显示“预计新增”“重复”“冲突”；完全重复的记录跳过。同 ID 或同账号但内容不同的记录，可以逐条选择：

- **两份都留（默认）**：添加备份记录，ID 冲突时生成新 ID，备份中的 2FA 关联随之调整。
- **保留现有**：保留本机记录，跳过此备份记录；新导入的验证码关联到所选本机账号。
- **使用备份**：替换对应整条记录，保留本机 ID；密码不同会将当前密码加入历史，并在最近 10 条的范围内保留历史。

新增数量随选择更新，冲突数量不等于新增数量。2FA 按密钥、算法、位数和周期去重；相同配置保留现有名称和关联，已移除与使用中的记录分别处理。找不到对应账号的备份关联会清除，避免误连到同 ID 的其他账号；回收站账号的关联会跟随合并后的账号 ID，在恢复账号后继续使用。

默认保留当前设置。可分别勾选“插件偏好与安全设置”“黑名单与静默规则”“站点识别规则”“字段映射模板与导入进度”。勾选后使用备份中的整组配置替换本机该组配置，不逐条合并；未选组保持不变。合并不会把备份里的导出时间当成本机已完成备份的时间。

**替换**使用备份的全部数据、主密码和设置。确认对话框会再次说明。旧页面的会话随替换失效，需重新打开或解锁。

若预览后其他页面修改了密码库，必须重新预览。每次合并或替换前保留一份本机加密恢复点，最多保留最近 3 份。可下载恢复点再在恢复面板导入，需使用恢复点创建时的主密码。

## 备份提醒

- 无备份且有记录或自定义设置时提醒。
- 已有备份、记录有变化且距离上次导出至少 7 天时提醒。
- 偏好、黑名单、站点规则、字段映射或导入进度变化时直接提醒。
- 旧版导出状态未记录设置基线，升级后建议重新导出一次。

可关闭提醒。导出会在同一次写入事务内读取最新密码库并更新变化基线。界面显示的是“发起备份导出”，浏览器没有提供文件保存完成的确认；请确认下载文件仍在。
