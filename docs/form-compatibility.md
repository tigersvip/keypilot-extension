# 填表可靠性与固定样例（1.16）

快捷键 `Ctrl+Shift+L` 继续按当前表单选择账号或个人资料。资料填写先预览，保留已有值，完成后支持撤销，不自动提交资料表单。

## 本轮改进

- 下拉框同时核对字段含义和选项。空占位、禁用项、重复候选及只有相同值的无关下拉框不会被误选；国家、州、月份和年份的别名分开处理。月份优先采用可见名称，兼容从 0 编号的网站。
- 日期支持年在前的数字/中文格式、明确的日月顺序、英文月份和网站 `DD/MM/YYYY`、`MM/DD/YYYY` 等提示。原生日期控件写入规范值，拒绝无效日期、自动日期进位和 `03/04/1990` 这类月日不明的来源。请把有歧义的资料改为 `YYYY-MM-DD`；卡有效期可用 `MM/YY` 或 `YYYY-MM`。
- 已校准的字段位置变化后，只在原字段类型、含义仍一致且目标唯一时恢复。原 ID 被其他字段占用、只剩位置索引或出现多个候选时提示重新校准，预览展示具体原因。
- 确认前和逐项填写期间检查目标字段、已有内容及下拉选项是否变化。页面更新或用户编辑使旧计划失效时停止相应填写。

国家别名目前包括 US、CN、CA、GB、AU、NZ、DE、FR、JP、SG、IN、KR、HK、TW；州缩写支持美国州。其他国家/地区仍可按原始值或完整名称精确匹配。自绘控件、跨源框架、复杂地址联动及所有语言日期尚未全面覆盖。

## 自动回归

```bash
npm ci
npx playwright install chromium
npm run build
npm run test:forms
```

34 个固定合成表单来自 `tests/fixtures/formCompatibility.ts`，另有确认前变化及填写中变化两项用例。每次运行使用独立 Chromium、虚构资料和本地拦截的网页，不连接测试域名、不打开用户浏览器配置，也不提交表单。自动测试检查最终字段值、未计划的改动、填写数量、是否误提交及页面错误。

报告和桌面/窄屏截图写到系统临时目录 `keypilot-forms-v1.16.0`。报告的 `complete` 必须为 true，且测试全部通过才代表本组完成。`elapsedMs` 包含测试驱动等待和部分截图开销，`confirmationActions` 只计测试中的预览确认，均不代表真人操作时间。成功保留应跳过的字段也计入正确结果，所以不能把它当成自动填充覆盖率。

## 与其他插件进行同条件比较

```bash
npm run forms:lab
```

浏览器打开终端输出的本机地址 `http://127.0.0.1:4174`，选择样例，展开“测试资料与预期结果”。服务仅监听本机，不进入插件安装包。结束时按 Ctrl+C。

1. 使用空白测试配置，每次只启用一个插件，统一浏览器版本、语言、缩放和合成资料。测试域名与本机地址的绑定需要分别创建，不能直接复用自动测试的域名配置。
2. 记录插件版本、样例 ID、自动正确填写数、应填却漏掉数、写错或误改数、手动修正次数和从触发到完成的实际操作时间。绑定变化样例先保存原绑定，再模拟移动或改义，记录这一步骤。
3. 至少重复三次，并分别记录首次使用与已经校准后的结果。不要省略失败样例，不把需要手动填写的结果记成自动成功。
4. 合成样例通过后，再选经授权的真实网站验证登录、地址、付款和双重验证流程。记录日期和网站版本，避免真实付款或误提交。

**目前没有 RoboForm 实测数据，也没有真实网站总体成功率。** 这组样例是可复现的回归基线，不能据此声称 KeyPilot 已全面领先。Passkey、跨设备同步、手机端及第三方安全审计仍是独立工作。
