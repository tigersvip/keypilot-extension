# 身份验证器与备份提醒（1.6）

管理页侧栏选择“身份验证器”，或在扩展弹窗的“更多操作”中进入。

点击“添加验证码”，粘贴网站提供的 Base32 密钥或 `otpauth://totp/` 设置链接。链接可以直接保存，也可点击“读取密钥或链接”检查账号及参数。

## 从 Google 身份验证器导入

1. 在手机 Google 身份验证器中打开菜单 → 转移账号 → 导出账号，选择需要的账号。
2. 在 KeyPilot 的“身份验证器”中点击“导入二维码”。可选择二维码图片、粘贴图片，或点击“摄像头扫描”直接扫描手机屏幕。
3. 如果 Google 分成多张二维码，请逐张扫描或一次选择所有图片。页面会显示“已读取 X / Y 张”，全部读取后才能导入。
4. 检查服务和账号名称，勾选需要的账号，再点击“导入所选”。预览不会改动密码库，重复账号自动跳过。

无需记住最初的密钥。摄像头需要浏览器授予访问权限；建议在管理页扫描，关闭扫描、离开页面或锁定密码库后会停止摄像头。图片处理不需要联网，也不会上传图片或密钥。

图片支持 PNG / JPG / WebP / BMP，单张不超过 10 MB；一次可选择 20 个文件，预览最多 100 个二维码、1000 个账号。二维码应完整、清晰；图片较大时可裁剪到二维码区域。

Google 导出步骤参考 [Google 官方帮助](https://support.google.com/accounts/answer/1066447?hl=zh-hans)。

1.4.2 修复了旧版只允许迁移格式版本 0/1 的限制。结构兼容的二维码会继续检查账号字段，不再仅因版本号不同而拒绝；这不代表支持任意未来格式或加密备份。修改后请重新加载扩展，并重新打开身份验证器页面再导入。

## 其他格式与范围

| 格式 | 支持情况 |
| --- | --- |
| Google `otpauth-migration://offline` 迁移二维码或链接 | 支持批量账号、多张二维码和重复识别 |
| 网站或其他验证器提供的标准 `otpauth://totp` 二维码或链接 | 支持，保留算法、位数和周期 |
| TXT，每行一个上述链接 | 支持预览和选择性导入 |
| Base32 设置密钥 | 使用“添加验证码”输入，并填写账号名称 |
| 当前显示的 6 / 8 位数字 | 不能作为导入密钥，它们是临时验证码 |
| HOTP、Steam 专用格式、推送批准、其他应用的专有/加密备份 | 暂不支持，不能按普通 TOTP 导入 |

支持 SHA1 / SHA256 / SHA512、6 / 8 位及自定义整数秒周期；默认 SHA1、6 位、30 秒。Google 迁移格式采用 30 秒周期。混合迁移中不支持的账号会列出跳过原因，确认后可导入其余支持的账号。

## 关联账号并填写验证码

验证器列表的“更多 → 编辑与关联”可以选择登录账号；登录账号详情也可以关联尚未绑定的验证码。一个账号可以关联多个验证器，操作时选择对应的一条。编辑名称或参数会保留关联。

打开网站的两步验证页面，在关联的验证码旁点击“填写验证码”，选择目标网页后确认。支持带验证码语义的单个输入框、6/8 位分格输入和同源 iframe。多个候选时先点击网页内的目标输入框；已有其他内容时先清空。网站匹配沿用账号的匹配网址规则，HTTPS 账号不会向 HTTP 页面填写，跨源 iframe 不接收验证码。

临近过期时会要求等待下一组，填写时重新计算当前验证码。只把当次数字交给网页，密钥留在扩展内。插件不点击提交，网站自身可能在收到完整验证码后自动继续。设备时间需要准确；特殊自定义控件可使用复制。

## 一键登录自动填写（1.10.0）

在登录账号详情关联身份验证器，展开“此网站设置”，开启“**一键登录后自动填写动态验证码**”。同时需要开启全局与此网站的自动点击登录选项。网站开关默认关闭，按完整 HTTPS 来源（协议、域名、端口）保存，同一来源下其他具备明确验证码关联的账号也适用。

只关联一组时自动使用这一组；关联多组时，在“本账号默认动态验证码”中指定一组。该选择只针对当前登录账号。所选记录被删除、解除关联或已不匹配时会停止，不会擅自改用另一组。

明确发起一键登录后，支持两类流程：

- 密码和 TOTP 在同一个明确的表单中：填写验证码，然后随本次登录提交一次。验证码将过期时先等待下一组。已有验证码或无法唯一定位时暂停；密码或设置在等待期间发生变化时不继续。
- 登录后出现验证页：两分钟内等待跳转或动态字段，支持 6/8 位分格输入及同源 iframe。填写一次，不点击独立的 2FA 提交按钮，网站自身可能自动继续。

网页右下角显示等待新验证码、已填写或需要手动处理的原因，并可打开账号详情手动选择验证码。关闭提示只关闭显示，不代表取消已经发起的登录。

必须确认字段属于身份验证器。短信、邮件、恢复码、仅写“验证码”且没有验证器提示的字段、多个目标输入组、已有内容及跨源验证页面继续保留手动入口。密码与 TOTP 同时出现但无法确认属于同一表单时，也保留手动填写。锁库、关闭开关、修改关联账号或过期后停止。

自动填写的网站开关及默认验证码选择随完整加密备份保存，归入“站点识别规则”恢复组。恢复默认网站设置不会删除账号、2FA 密钥或关联关系。
