# 轻量数字识别原型

状态：v2 数字引擎已在 1.8.1 接入插件；1.8.2 的网页流程改为通用识别与数字模板自动复核，不再要求选择字符类型。此页面仅验证冻结的数字模板，不代表插件完整自动流程，也不操作网站表单。真实网站样本验收尚未完成，下面的数字均为合成图片测试结果，不是网站覆盖率。

## 打开与使用

运行 `npm run ocr:build` 后，双击 `ocr-lab-dist/KeyPilot-数字识别原型.html` 即可使用，无需服务器、安装扩展或联网。目录中的 `keypilot-digit-lab-prototype-v2.zip` 仅包含这份 HTML，不是扩展安装包。点击“试用背景示例”可查看渐变、杂点、浅色细线和网格的合成演示。

选择 PNG、JPEG、WebP 或 BMP 验证码图片，保留原始大小；每张不超过 5 MB，验证码区域 8–1800 × 8–600 像素，一次最多保留 30 张。当前原型只识别数字 0–9。填写“正确答案”后按整张完全一致统计，前导零会保留；未填写答案的图片不进入准确率分母。

已知验证码位数时，可以选 4、5 或 6 位。分离出的字符数不同则返回不匹配，不补零、不猜缺失字符。自动模式不会预设四位，因此不能凭它保证没有漏字。字符粘连、未知字体或非数字可能识别失败或产生错误候选；所有结果都要人工核对。

图片、预期答案和识别结果只保存在当前页面内存中。清空或重新打开页面后消失，不上传、不保存到浏览器存储，不操作网站表单。

## 实现与体积

- `src/ocr-lite/digits.ts`：纯 TypeScript 的背景分离、连通区域处理、归一化字符特征和模板匹配。对小字号抗锯齿保留较细笔画，避免数字“0”断裂、“1”被过滤。
- `src/ocr-lite/digits-v1.bin.gz`：2,400 个数字字形模板，来自本机字体渲染；不分发字体文件，不包含神经网络或 WASM 推理运行库。模板按原始字节校验散列，压缩只是无损传输方式。
- `tools/ocr-lite/`：独立验证页面、生成脚本、基准对比脚本和单文件打包。使用项目已有的 fflate 解压模板，没有新增依赖。
- 压缩模板 167,205 字节，解压特征 1,351,212 字节。更新 1.8.1 接入说明后的 v2 完整单文件页面 244,953 字节，ZIP 为 184,835 字节；相较 v1 ZIP 只增加 1,716 字节。模板和依赖未增加。
- 这只证明简单数字识别可以做到小体积，不能推广为数字与所有字母验证码的通用识别方案。

## v2 背景处理与验证（2026-11-10）

用边缘中位数估计渐变背景，在不模糊字形的情况下分离前景；增加不同阈值和主笔迹颜色过滤，利用抗锯齿颜色与笔迹的一致性排除部分异色线条。多种分离结果一起评估，候选冲突时提示不确定；无法稳定分离或字符数冲突时拒识。不删除同色线后强行补笔，不凭指定长度补字。

原图能够读出数字时保留其字符数量，避免强过滤把细笔画擦掉后，因短结果得分更高而优先输出。较远的杂点不再与字符合并；碎片超过 256 个时停止两两合并，限制纯噪声图片的计算量。空白渐变图不会从边缘色块中生成数字候选。

开发回归沿用上一轮 240 张简单数字和 120 张背景样本；这部分现为开发回归数据，不再算独立验收。简单数字保持 238/240；背景样本中纯色、浅渐变、杂点、浅线各 20/20，穿字线 9/20、网格 11/20，其余强干扰样本拒识。合成样本太少，不能由此声称不误识别。

冻结 v2 算法后，另用预先固定的种子 `887312` 生成 200 张新样本。每类 40 张；4／5／6 位，Tahoma／Verdana／Calibri／Georgia，20–32 px，普通／粗体，轻微旋转及随机背景位置。与保存的 v1 单文件原型逐张比较同一图片，拒识算失败，未依据这批结果继续修改识别算法。

| --- | ---: | ---: | ---: | ---: | ---: |
| 渐变 | 40 | 39 | 40 | 0 | 0 |
| 杂点 | 40 | 31 | 38 | 0 | 2 |

## v1 基准与历史验证

下列 v1 数据保留作历史记录；在 v2 中已转为回归数据，不再作为独立验收。

运行本地开发页：

```powershell
npm run ocr:lab
```

在另一个终端运行：

```powershell
# 使用随仓库保存的冻结模板进行验证，不必重新生成。
npm run build
npm run ocr:benchmark
npm run ocr:benchmark -- --holdout
npm test
npm run ocr:build
```

基准程序在隔离 Chromium 配置中调用对照目录内的实际打包引擎，并对同一张图片运行验证页；不使用用户密码库或浏览器登录状态。默认对照目录为 `dist`，输出明确记录其 manifest 版本；可用环境变量 `KEYPILOT_OCR_BASELINE_DIR` 指向解压的旧版本。1.8.1 中数字模式和验证页使用同一引擎，默认对比不再是旧 Tesseract 基准。输出位于系统临时目录 `keypilot-ocr-lite/`，文件名包含对照版本，避免覆盖此前的历史结果。

开发组使用 Arial、Tahoma、Times New Roman、Consolas、Trebuchet MS、Courier New，随机种子 13241；字体家族与模板相同，属于开发数据，不能当成独立准确率。冻结模板与算法后，独立组使用 Verdana、Georgia、Segoe UI、Calibri、Palatino Linotype、Cambria，随机种子 739391。独立组未参与建模板与阈值调整；不要依据这些结果调整后仍称同一组为独立验收。

两组都包含 4／6 位数字、16–35 px 字号、粗细字重、不同间距、轻微逐字旋转、浅底、深底和透明背景。全部按整张完全一致计分，拒识也算失败。
